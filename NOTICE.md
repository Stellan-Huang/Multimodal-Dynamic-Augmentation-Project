# Notices and provenance

## Research source

This repository presents a compact reference implementation of algorithmic ideas described in:

Haining Li, Shan Huang, and Changqing Zhang, "Multimodal Data Augmentation for Dynamic Fusion," *2025 International Joint Conference on Neural Networks (IJCNN)*, 2025. DOI: [10.1109/IJCNN64981.2025.11228982](https://doi.org/10.1109/IJCNN64981.2025.11228982).

The paper is an IEEE publication. This repository includes citation metadata only; it does not redistribute the IEEE PDF, publisher-formatted figures, or tables.

## Historical source archives reviewed

The supplied historical archives were reviewed as provenance references. They contained, among other things:

- a `Depth-Red` code tree with a Facebook, Inc. copyright header in `models/QMF.py`; that header refers to a root `LICENSE` file that was not present in the supplied archive;
- an `mmdynamics-main` code tree whose README identifies Tencent AI Lab as the copyright holder and states "All rights reserved";
- nested third-party components with their own licensing notices, which do not automatically license the surrounding project.

The historical archives and their original source files are not included in this repository. The current implementation is organized as a compact reference presentation of the published method and recovered implementation patterns; it is not a verbatim copy of the historical training scripts.

This provenance note describes the package contents and review rationale. It is not a legal opinion or a formal clean-room certification. If any historical source file or third-party component is later introduced, its origin, license, required notices, and redistribution permissions must be checked before publication.
