# Method overview

## 1. Problem setting

A multimodal sample contains modality-specific observations

\[
 x_i = \{x_i^m\}_{m=1}^{M}, \qquad y_i \in \mathcal{Y}.
\]

The quality of each modality may vary across samples and environments. A dynamic fusion model should estimate modality-specific reliability rather than assigning a fixed contribution to every input source.

The paper addresses a training-data limitation: if the training set contains few examples with heterogeneous modality quality, a model may not learn a robust uncertainty-to-weight relationship.

## 2. QMF foundation

For modality \(m\), let \(f^m(x_i^m)\) be its classifier logits and \(u^m(x_i^m)\) its uncertainty. The decision-level fused output is

\[
 f(x_i)=\sum_{m=1}^{M} w^m(x_i^m) f^m(x_i^m),
 \qquad
 w^m(x_i^m)=\alpha^m u^m(x_i^m)+\beta^m,
\]

where \(\alpha^m<0\) and \(\beta^m\geq 0\). The energy-based uncertainty is

\[
 u^m(x_i^m)=-\tau^m\log\sum_{k=1}^{K}
 \exp\left(f_k^m(x_i^m)/\tau^m\right).
\]

The reference model implements this energy score and linear weighting. It intentionally does not apply a softmax across modalities: the QMF formulation uses a weighted sum of modality logits. The implementation accepts either one shared temperature or a separate positive temperature for each modality.

QMF is the uncertainty-aware fusion foundation used by the paper. It should not be confused with the data-augmentation contribution described next.

## 3. Single-modal low-quality augmentation: AW + SR

For each modality, an adversarial counterpart \(\hat{x}_i^m\) is generated by increasing classification loss while decreasing its fusion weight and constraining the feature representation:

\[
 \mathcal{J}_{adv}^m =
 \mathcal{L}_{CE}(y_i,f^m(\hat{x}_i^m))
 -\mu w^m(\hat{x}_i^m)
 -\gamma d(h^m(\hat{x}_i^m),h^m(x_i^m)),
\]

where \(h^m\) is the penultimate-layer representation and \(d\) is a feature distance. The input is updated by gradient ascent on this objective; model parameters are not updated during the generation step.

- **AW (Adversarial Uncertainty Weight):** the classification and confidence terms create model-aware low-quality inputs instead of relying only on manually chosen corruption types.
- **SR (Semantic Similarity Regularization):** the feature-distance penalty discourages the adversarial input from drifting too far from the original sample's semantic representation.

The paper describes the similarity term as a negative L2 feature distance. The recovered training scripts use `MSELoss` on penultimate features; the reference code follows that implementation convention and documents the distinction. MSE and squared L2 distance differ by their reduction/normalization, so the coefficient scale is implementation-dependent.

## 4. Multimodal mixing augmentation: MA + RR

Once a low-quality counterpart has been generated for every modality, the method constructs a mixed sample by choosing either the original or low-quality version for each modality:

\[
 \tilde{x}_i^m \in \{x_i^m,\hat{x}_i^m\},
 \qquad
 \exists m:\tilde{x}_i^m\ne x_i^m.
\]

At least one modality must be degraded. With \(M\) modalities there are \(2^M-1\) non-empty degraded subsets. For two modalities there are three possibilities; for three modalities there are seven.

The augmentation ranking loss is

\[
 \mathcal{L}_{rank}=
 \frac{1}{N}\sum_{i=1}^{N}\frac{1}{n_i}
 \sum_{m=1}^{M}
 \max\left(0,w^m(\tilde{x}_i^m)-w^m(x_i^m)\right),
\]

where \(n_i\) is the number of degraded modalities in sample \(i\). This enforces that a degraded modality should not receive a larger confidence weight than its original counterpart.

## 5. Two ranking mechanisms, two roles

The paper also uses a historical-loss ranking regularizer in the QMF foundation. For modality \(m\), the historical average classification loss is

\[
 \kappa_i^m=\frac{1}{T}\sum_{t=T_s}^{T_s+T-1}
 \mathcal{L}_{CE}(y_i,f_{\theta_t^m}^m(x_i^m)).
\]

It regularizes the relation

\[
 \kappa_i^m\geq\kappa_j^m
 \quad\Longleftrightarrow\quad
 w_i^m\leq w_j^m,
\]

using the pairwise hinge form in Eqs. (6)-(7). This historical regularizer is distinct from the augmentation ranking loss above.

The reference implementation stores per-sample loss sums and observation counts. To reproduce a particular historical window, the caller should reset the buffers before the window, update them only during the intended \(T\) observations, and then stop updating them while the ranking term is used. The default cyclic pair sampler is an implementation choice; it is not an exhaustive all-pairs enumeration.

## 6. Joint training objective

The original QMF objective combines fused classification, per-modality classification, and historical ranking:

\[
 \mathcal{L}_{overall}=
 \mathcal{L}_{CE}(y,f(x))
 +\sum_m\mathcal{L}_{CE}(y,f^m(x^m))
 +\lambda\mathcal{L}_{reg}.
\]

The augmentation objective applies the same classification terms to the mixed batch and adds augmentation ranking:

\[
 \mathcal{L}_{aug}=
 \mathcal{L}_{CE}(y,f(\tilde{x}))
 +\sum_m\mathcal{L}_{CE}(y,f^m(\tilde{x}^m))
 +\epsilon\mathcal{L}_{rank}.
\]

The training algorithm minimizes \(\mathcal{L}_{overall}+\mathcal{L}_{aug}\).

## 7. Scope of this reference implementation

The code provides the core tensor-level operations and synthetic examples. It does not include dataset-specific encoders, preprocessing, data loaders, original splits, checkpoints, or benchmark evaluation scripts. The examples therefore demonstrate how the modules connect; they do not reproduce the paper's experimental pipelines or results.
